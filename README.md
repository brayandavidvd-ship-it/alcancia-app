# 🐖 Alcancía - App de Ahorros (Versión 1.0)

Una aplicación móvil moderna, minimalista y 100% privada para gestionar tus metas de ahorro, diseñada y desarrollada con la ayuda de Google AI Studio[span_1](start_span)[span_1](end_span).

## ✨ Características Principales

* **🔒 100% Privada y Local:** Tus datos se guardan únicamente en el almacenamiento seguro de tu dispositivo. Sin servidores externos ni recopilación de información[span_2](start_span)[span_2](end_span).
* **🛡️ Cero Anuncios ni Rastreadores:** Totalmente libre de publicidad, SDKs de analítica en segundo plano y consumo innecesario de batería[span_3](start_span)[span_3](end_span).
* **🎨 Personalización Total:** Soporte para Material You (colores dinámicos), temas rápidos, acentos de color personalizados, modo oscuro/claro y estilos de tarjetas[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
* **🔐 Seguridad Avanzada:** Opciones de bloqueo mediante huella digital (biometría) y código PIN de acceso.
* **⏰ Recordatorios Inteligentes:** Notificaciones locales personalizadas para tus aportes con optimización de batería en segundo plano para garantizar puntualidad exacta.
* **💾 Respaldos y Exportación:** Crea respaldos completos de la app o exporta tus movimientos en formato CSV para consultarlos en Excel o Google Sheets[span_6](start_span)[span_6](end_span).

## 🛠️ Requisitos de Compilación (F-Droid Ready)

Este proyecto cumple con las directrices de código abierto y software libre requeridas por **F-Droid**:

1. Abrir [Android Studio](https://developer.android.com/studio)[span_7](start_span)[span_7](end_span).
2. Seleccionar **Open** y elegir el directorio raíz del proyecto[span_8](start_span)[span_8](end_span).
3. Compilar el APK de producción utilizando Gradle.
